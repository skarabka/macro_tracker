# Macro Tracker

Проста PWA для моніторингу калорій і БЖВ.

## MVP
- денний прогрес kcal / білків / жирів / вуглеводів;
- додавання їжі вручну, фото або фото етикетки;
- історія;
- статистика за 7 днів;
- денні норми;
- локальний офлайн-режим і черга синхронізації;
- Google Sheets + Google Drive через Google Apps Script.

Frontend розрахований на статичний деплой у Vercel.

Backend Web App уже налаштований через Google Apps Script.
